# Changelog

## 1.0.0 (October 2026)

- First release, built from 86 peer-reviewed HCI papers (1954–2024) and WCAG 2.2, each read in full text.
- `SKILL.md` with 14 core principles, a numbers card, design and review workflows, and a table of misread findings.
- 12 reference files with 252 rules, each graded [A], [B] or [C] for strength of evidence and tied to its sources.
- A review procedure for Claude acting as a UI critic, built around the failure modes measured in published studies of LLM design critique.
- Paper-by-paper summaries and a bibliography with DOIs in `research/`.
